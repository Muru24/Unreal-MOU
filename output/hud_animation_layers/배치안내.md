# HUD 이미지 배치

모든 파일은 PNG이며 외곽에 투명 알파가 있습니다. 회색 배경이 있는 Preview 파일은 확인용입니다.

원본 1672×941 캔버스의 왼쪽 위를 (0, 0)으로 잡았을 때:

| 구성 | 위치 X, Y | 크기 W, H | 기본 / Emissive |
|---|---|---|---|
| 원형 프레임 + 짧은 연결부 | 205, 193 | 619, 535 | 01 / 02 |
| 기둥 연장부 | 824, 280 | 704, 367 | 03 / 04 |
| 원형 내부 디테일 | 258, 242 | 440, 440 | 05 / 06 |
| 전체 조립본 | 0, 0 | 1672, 941 | FullFrame_Base / FullFrame_Emissive |

원형 프레임 이미지의 왼쪽 위를 새 기준 (0, 0)으로 사용하면 기둥 위치는 (619, 87), 내부 디테일 위치는 (53, 49)입니다. 디테일은 원형 프레임 위에 배치합니다.

기둥 원본 크기는 704×367입니다. 펼침 애니메이션에서는 기둥 이미지를 이 크기로 유지한 채, 가리는 영역만 왼쪽부터 열어주도록 사용합니다. 재조립할 때 각 부품을 따로 늘리지 말고 동일한 배율을 적용하세요.

각 기본/Emissive 쌍은 같은 크기와 알파를 갖습니다. Emissive의 검정 영역은 빛이 없는 영역이며, 별도의 불투명 이미지로 위에 덮기 위한 배경이 아닙니다. 한 머티리얼에서 기본 RGB와 Emissive RGB를 조합하고 해당 부품의 알파를 사용하도록 만든 텍스처입니다.

05:00 숫자는 제거했습니다. 내부 디테일에는 원형 링, 눈금, 고정된 게이지 모양이 포함되어 있습니다. 게이지 자체의 진행도를 조절하는 별도 마스크는 이번 파일에 포함되지 않습니다.

이미지 조립 및 알파 확인 완료. 실제 UMG 애니메이션 적용 테스트는 수행하지 않았습니다.
